# DevOps Chronicles

A structured log of my hands-on journey into DevOps - covering Linux systems administration, version control, CI/CD pipelines, containerization, orchestration, and cloud infrastructure.

## About

This repository documents concepts, commands, and projects as I work through them, with a focus on understanding not just *how* a tool works, but *why* it's used and *where* it fits in the broader software delivery lifecycle — from code to build, test, and deployment.

## Topics Covered

- Linux fundamentals & shell scripting
- Version control with Git
- Continuous Integration / Continuous Deployment (CI/CD)
- Containerization with Docker
- Container orchestration with Kubernetes
- Cloud infrastructure on AWS

## Tech Stack

`Linux` · `Git` · `Jenkins` · `Docker` · `Kubernetes` · `AWS`
